# 个人日常看板 · 手机端

Chris 的私人「今日工作日历」手机页，用来在手机上快速看当天的待办、硬截止和日程。

- **无索引**：页面自带 `<meta name="robots" content="noindex, nofollow">`，本仓库另有 `robots.txt` 全站 `Disallow: /`。
- **内容每日覆盖**：`index.html` 由本地构建脚本从只读数据生成的**自包含单文件**（数据内联，不发请求），每次发布整页覆盖。
- **不含敏感内容**：只放日程与待办这一层，不含复盘正文、金额/股权数字、证件或聊天原文。
- **请勿分享此 URL。**

> 这是一个公开仓库，仅靠"不可检索"降低曝光，并非私有。
